## What the app implements

`SubscriptionStore` owns the transaction listener for the app lifetime. It accepts only StoreKit-verified auto-renewable transactions for the two known products and refreshes access at launch / foreground. Local access is bounded by the verified transaction expiry; an expired transaction requires Apple's verified renewal info and a future billing-grace expiry. A timer removes expired local access and refreshes for renewal/grace while the app stays open. Release builds ignore Xcode-local purchases; Debug keeps StoreKit Test support. A just-confirmed, unrevoked, unexpired purchase can deliver access before StoreKit publishes it in current entitlements, with the same expiry timer. Concurrent refreshes are coalesced, and verified transactions are finished after processing access.
